# Using holo-cards

This guide shows how to put a card on a page, open it full screen, restyle it and work on the library itself. For how the effect is built, see [architecture.md](architecture.md).

## Quick start

```ts
import { mountHoloCard } from "./src/core";
import "./src/styles/index.css";

mountHoloCard(
  document.querySelector("#slot")!,
  {
    rank: "epic",
    kind: "Breakthrough",
    number: "AC-042",
    title: "Liftoff",
    description: "Finished the course twice as fast as planned.",
    art: { emoji: "🚀" },
  },
  { openOnClick: true },
);
```

The card takes the width of its container; the height follows the 5 : 7 ratio.

## API

| Function                                    | What it does                                                                                                |
|---------------------------------------------|-------------------------------------------------------------------------------------------------------------|
| `mountHoloCard(container, card, options)`   | Renders a card, binds the tilt, optionally opens the viewer on click. Returns `{ element, open, destroy }`. |
| `renderCard(card, { locked, pressable })`   | Builds the markup only.                                                                                     |
| `bindTilt(element, { maxTilt, gyroscope })` | Makes any rendered card follow the pointer. Returns an unbind function.                                     |
| `openViewer(card, { from, hint, onClose })` | Shows a card full screen. With `from`, the card flies out of that element and back.                         |

## Card data

A card is described by `HoloCardData`:

| Field         | Type                             | Notes                                              |
|---------------|----------------------------------|----------------------------------------------------|
| `rank`        | `Rank`                           | one of the ranks listed in `RANKS`                 |
| `title`       | `string`                         |                                                    |
| `description` | `string`                         | optional                                           |
| `kind`        | `string`                         | optional, top-left caption                         |
| `number`      | `string`                         | optional, top-right caption                        |
| `rankLabel`   | `string`                         | optional, overrides the rank name for localisation |
| `art`         | `{ emoji }` or `{ image, alt? }` | an emoji or an image URL                           |

## Theming

Every visual value is a custom property on `.hc-card`, so a rank or a single card can be restyled without touching the layers:

```css
.hc-card[data-rank="rare"] {
  --hc-glow: #00c2ff;
  --hc-gem: #0077ff;
}

.hc-card {
  --hc-font-display: "Inter", sans-serif;
  --hc-tex-grain: url("/my-grain.webp");
}
```

To add a rank, copy one of `src/styles/ranks/*.css`, rename the selector and add the rank to `RANKS` in `src/core/types.ts`. [architecture.md](architecture.md) explains the layer stack and the variables the tracker writes.

## Development

```sh
npm install
npm run dev                          # demo with every rank
npm run build                        # type check and build
python3 scripts/gen-textures.py      # regenerate the textures
node scripts/record-demo.mjs <url> nebula,mythic epic,prismatic   # re-record media/<a>-<b>.gif from a running dev server
```

All textures are generated by `scripts/gen-textures.py` with a fixed seed, so the repository ships no third-party images.
